e no crescimentos das vendas.

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de apresentar a
história e tragetória da empresa e com objetivo também de apresentar e vender nossos produtos através 
das funcionalides que leva o cliente aos contatos da empresa e central de vendas.

## 🚀 Como executar o projeto

### Pré-requisitos

- Git instalado.
- Node.js e npm, caso o projeto utilize essas ferramentas.

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/Pedroita-057/R4-alimentos.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd meu-projeto
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie a aplicação conforme a configuração do projeto:

   ```bash
   npm run dev
   ```

   Abra o arquivo `index.html` no navegador ou utilize um servidor local.
